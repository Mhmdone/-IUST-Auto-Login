حتماً. متن زیر را می‌توانی **تقریباً بدون تغییر به Agent دیگری بدهی**. سعی کرده‌ام هم هدف پروژه، هم معماری، هم جریان Login، هم جزئیات Linux، Selenium، systemd، امنیت Credential و تست را مشخص کنم؛ اما Agent نباید از اطلاعاتی که هنوز تأیید نشده‌اند حدس بزند.

# دستورالعمل کامل ساخت پروژه IUST Auto Login

## 1. هدف پروژه

یک نرم‌افزار واقعی برای **Linux/Ubuntu** با Python بساز که بتواند فرآیند اتصال به اینترنت دانشگاه صنعتی خواجه نصیر/شبکه دانشگاه را کاملاً خودکار کند.

کاربر در حالت فعلی مجبور است هر بار:

1. به Wi-Fi دانشگاه متصل شود.
2. صفحه Login دانشگاه را باز کند.
3. Username و Password را وارد کند.
4. Login کند.
5. وارد صفحه دیگری روی IP داخلی دانشگاه شود.
6. با هشدار امنیتی مرورگر مواجه شود.
7. روی **Send anyway** کلیک کند.
8. در نهایت اینترنت فعال شود.

هدف پروژه این است که کاربر **فقط یک بار Credential را تنظیم کند** و پس از آن نرم‌افزار تمام این فرآیند را به‌صورت خودکار انجام دهد.

# 6. مرحله دوم Login

بعد از ارسال اطلاعات Login، کاربر وارد صفحه‌ای با آدرس:

```text
http://192.168.253.14/login
```

می‌شود.

این صفحه روی HTTP است، نه HTTPS.

مرورگر در این مرحله هشدار امنیتی نشان می‌دهد و کاربر فعلی باید روی:

```text
Send anyway
```

کلیک کند.

برنامه باید این مرحله را نیز خودکار کند.

**نکته مهم:**

Agent نباید فرض کند ساختار HTML این صفحه دقیقاً چیست.

باید ابتدا با Selenium صفحه را بررسی کند و:

* title
* URL
* buttons
* links
* forms
* DOM

را بررسی کند.

سپس selector مناسب برای `Send anyway` پیدا شود.

Selector شکننده مثل XPath بسیار وابسته به متن/ساختار صفحه تا حد امکان استفاده نشود.

# 7. نکته بسیار مهم درباره هشدار HTTPS/HTTP

هدف پروژه این نیست که certificate verification سیستم Linux را خاموش کند یا امنیت کل سیستم را کاهش دهد.

فقط باید همان فرآیندی که کاربر در مرورگر انجام می‌دهد، به‌صورت کنترل‌شده توسط Selenium automation شود.

اگر Chrome/Chromium برای صفحه داخلی دانشگاه هشدار نشان داد، Agent باید ابتدا دقیقاً مشخص کند این هشدار مربوط به:

* Certificate
* HTTP form warning
* unsafe page
* redirect
* captive portal

است.

بعد راهکار مناسب انتخاب شود.

نباید بدون بررسی، Chrome را با flagهای امنیتی خطرناک اجرا کرد.
